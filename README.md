# オービスマップ for Android

Android 8.0以降で使える地図とオービス接近通知アプリです。APIキー、アカウント、専用サーバーは不要です。

## 使い方

1. 「通知を開始」を押し、正確な位置情報と通知を許可します。
2. 走行中、進行方向の登録地点に接近すると通知します。通知を開始してからは、画面を消したり、別のアプリに切り替えたりしても監視が続きます。
3. 「設定」で通知距離を300 m・500 m・700 m・1 km・1.5 kmから選べます。初期値は700 mです。通知音と振動を試すには「通知音をテスト」を押します。
4. 「通知を停止」または常駐通知の「停止」でGPS監視を終了します。

地名・住所の検索結果か地図の長押しから、Google マップに車の経路を開けます。地図を長押しすると、端末内にオービス地点を追加できます。追加地点はピンの詳細から削除できます。

## データと通信

- 地図と同梱される地点データは © OpenStreetMap contributors です。 [出典とライセンス](https://www.openstreetmap.org/copyright)
- 同梱の [cameras.tsv](app/src/main/assets/cameras.tsv) は ODbL 1.0 です。2026年9月21日版から日本のオービス地点を抽出し、2026年11月22日に地点のタグを照合しました。196地点を収録しています。徳島県内には国道11号の松茂町と徳島市川内町が入っています。 [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/)
- 通知はGPSと同梱・追加地点を使って端末上で判定します。測位精度、速度、進行方向、地点との直線距離を使います。登録方向がある場合は走行方向も照合します。道路や車線へのマッチングは行わないため、並行する道路や曲線では誤通知や遅れが起こることがあります。
- 地図は表示範囲のタイルをオンラインで取得します。取得済みのタイルは端末にキャッシュします。地名検索は端末のAndroid Geocoderを使います。検索が使えない場合は検索画面からGoogle マップを開けます。
- 固定式と一部の半固定式を収録しています。登録内容はデータ更新時点のもので、移動式の出現情報や現地の稼働状況の配信はありません。

## ビルド

Android Studio でこのフォルダを開き、JDK 17とAndroid SDK Platform 35を指定してビルドできます。依存ライブラリはAndroid標準APIのみです。

SDKのコマンドラインツールで署名済みAPKを作る場合は Android SDK Build Tools 35.0.0、JDK、zip、OpenSSLを用意し、ビルドを実行します。

```sh
ANDROID_SDK_ROOT=/path/to/Android/Sdk bash build.sh
```

ビルド時に生成した署名鍵は `build/signing` に保存されます。同じインストールを更新するときは同じ鍵を使います。 `ORBIS_SIGNING_DIRECTORY` で鍵の保存先を指定できます。
